# Political Analyzer

An educational, single-page political-information site.

## 2026 SLO County Ballot Example

The homepage includes an expandable **2026 SLO County Ballot Example** with four
sections:

- Candidates on SLO County Ballot Type 1, including statewide, congressional,
  state legislative, and Paso Robles-area local contests
- Judicial retention questions
- All statewide propositions appearing on that ballot
- Local Measure G-26, the Paso Robles Joint Unified School District bond measure

A small starter website made with Codex.
Candidate priorities are plain-language paraphrases of voluntary official voter
guide statements; proposition descriptions are neutral summaries of the official
analyses. The feature also makes clear that local contests vary by address.

Primary sources are linked in the site footer: the SLO County Ballot Type 1
guide, the California Voter Information Guide, and the SLO County results report.
